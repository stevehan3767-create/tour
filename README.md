# 백운호수 푸르지오 숲속의 아침 여행동호회

경기도 의왕시 백운호수 푸르지오 숲속의 아침, 여행을 사랑하는 이웃들의 모임 홈페이지입니다.
회원가입 없이 누구나 공지사항과 여행 사진·영상을 보고, 올리고, 내려받을 수 있습니다.

## 주요 기능

- **홈 화면**: 관리자가 고른 대표사진 최대 5장이 2초 간격으로 자동 전환
- **공지사항**: 목록/상세, 관리자만 등록·수정·삭제 가능
- **여행앨범**: 여행 날짜별로 사진·영상·자료를 올리고, 보고, 내려받기
  - 사진: 1인당 1회 여행에 최대 10장, 원본 화질 그대로 저장
  - 영상: 1개당 최대 100MB
- **문의하기**: 회원가입 없이 바로 문의 남기기 (관리자만 목록 확인 및 답변)
- **관리자 모드**: 공지·여행·대표사진·문의 관리
  - 아이디: `lyjlmh`
  - 비밀번호: `lyjlmh1234`
  - (필요하면 `src/App.jsx`의 `ADMIN_ID`, `ADMIN_PW` 값을 바꿔서 비밀번호를 변경할 수 있습니다)
- 큰 글씨·이미지 중심의 단순한 화면 구성 (파란색·초록색 톤)

## 기술 구성 (모두 무료로 사용 가능)

- **Firebase Firestore**: 글, 날짜, 파일 링크 등 가벼운 정보를 저장하는 무료 데이터베이스
- **Cloudinary**: 사진·영상 원본 파일을 저장하는 무료 저장소 (25GB 저장 공간, 매월 25GB 전송량 제공, 신용카드 등록 불필요)

## 처음 설정하는 방법

### 1) 프로젝트 실행

```bash
npm install
npm run dev
```

### 2) 사진·영상 저장소(Cloudinary) 연결

사진과 영상은 Cloudinary에 저장됩니다. 아래 순서대로 무료 계정을 만들어 연결해주세요.

1. https://cloudinary.com 에서 무료 회원가입
2. 로그인 후 대시보드에서 **Cloud name** 확인
3. **Settings → Upload → Upload presets → Add upload preset**
   - Signing Mode를 **Unsigned**로 설정
   - Incoming Transformation은 비워두기 (사진 원본 해상도가 그대로 저장되도록)
   - 저장한 프리셋 이름 확인
4. 프로젝트 루트에 `.env` 파일을 만들고 (`.env.example` 참고) 아래처럼 입력

```
VITE_CLOUDINARY_CLOUD_NAME=본인의_클라우드_이름
VITE_CLOUDINARY_UPLOAD_PRESET=본인이_만든_프리셋_이름
```

5. 개발 서버를 다시 시작하면 사진·영상 업로드가 정상 동작합니다. (설정 전에는 화면 상단에 안내 문구가 표시됩니다)

### 3) 데이터베이스(Firestore) 준비

> ⚠️ **중요**: 지금 `src/firebase.js`에 들어있는 Firebase 프로젝트 설정은 원래
> 강릉 리조트 예약 사이트(별도 저장소/별도 이용자용)에서 쓰던 것을 임시로 재사용하고 있습니다.
> 여행동호회는 이용자 집단이 완전히 다른 별개 서비스이므로, **실제로 서비스를 시작하기 전에
> 반드시 이 프로젝트 전용의 새 Firebase 프로젝트를 만들어 교체**해주세요. 컬렉션 이름은
> `club_` 접두사로 분리해두었지만, 같은 Firebase 프로젝트를 계속 공유하면 나중에 한쪽을
> 정리하거나 삭제할 때 다른 쪽까지 영향을 줄 수 있습니다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 이 여행동호회 전용의 새 프로젝트를 생성
2. Firestore Database를 만들고, 아래 `firebaseConfig` 값을 확인
3. `src/firebase.js`의 `firebaseConfig` 값을 새 프로젝트 값으로 교체

이 사이트는 회원가입/로그인이 없는 구조이므로, Firestore 콘솔의 **규칙(Rules)** 메뉴에서
아래처럼 읽기·쓰기를 허용해야 정상 동작합니다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

> ⚠️ 위 규칙은 인증 없이 누구나 읽고 쓸 수 있는 매우 개방적인 설정입니다. 50명 규모의
> 소규모 동호회 내부용으로는 충분하지만, URL을 아무나 알 수 없도록 주의하고, 필요하면
> Firebase 콘솔에서 앱 체크(App Check) 등 추가 보호 장치를 검토해주세요.

### 4) 배포

`npm run build` 로 만들어지는 `dist` 폴더를 Netlify, Vercel, GitHub Pages, Firebase Hosting
등 무료 정적 호스팅 서비스에 올리면 됩니다.

## 처음 화면 예시 데이터

홈페이지를 처음 열면 실제 여행에서 찍은 사진들로 예시 대표사진과 예시 여행앨범이 자동으로
한 번 채워집니다. 관리자 로그인 후 여행앨범 메뉴에서 필요 없는 예시 데이터는 삭제하고,
실제 여행 사진으로 채워가시면 됩니다.

## 참고 사항

- 여행 등록 시 날짜는 매월 둘째 주 화요일이 기본값으로 제안되지만, 관리자가 자유롭게 바꿀 수 있습니다.
- 사진 다운로드는 Cloudinary의 강제 다운로드 링크를, 자료(문서)는 원본 링크를 사용합니다.
- 여행을 삭제하면 그 안의 사진·영상 기록도 함께 삭제되지만, Cloudinary에 저장된 원본 파일 자체는
  자동으로 삭제되지 않습니다. 완전히 지우려면 Cloudinary 대시보드에서 별도로 삭제해주세요.
